# 单人仓库管理系统（Termux 版）

从原《仓库进出管理.xlsm》提取结构改造而成：保留"物料行 × 每日进/出 × 汇总 × 预警"的布局思路，
改为**单据流水驱动**，库存自动计算，不再有原表 `#REF!` 损坏、公式不覆盖新行的问题。

## 一、安装（Termux 一次搞定）

```bash
pkg update && pkg install python
cd ~/storage/downloads/warehouse   # 或你解压到的任意目录
chmod +x run.sh
./run.sh
```

首次运行会自动装 Flask、建数据库 `warehouse.db`，并导入原表 32 种物料档案。
看到提示后，用手机浏览器打开 **http://127.0.0.1:8080**。

> 想换端口：`PORT=9000 ./run.sh`
> 想把数据库放别处：`WAREHOUSE_DB=/sdcard/wh.db ./run.sh`

## 二、五个页面（底部导航栏切换）

| 页面 | 用途 |
|---|---|
| 首页 | 今日/本月进出合计、库存预警清单、最近单据 |
| 台账 | 点物料行的 📈 看该物料逐笔进出与滚动结存 |
| **入库** | 📥 只做入库，A-G 七列齐全的表格，一次填多行 |
| **出库** | 📤 只做出库，带可用库存提示、超库存自动拦截 |
| 流水 | 全部单据；也可从入库/出库页进各自的流水 |
| 库存 | 实时库存 = 期初 + 入库 − 出库，可只看预警/零负 |
| 月报 | 复刻原模板：物料 × 每日进/出 × 汇总 × 月末结存 |
| 物料 | 档案增删改查，设置期初结存与安全库存（预警值） |

### 修改物料：两种方式，A–G 列全部可改

**① 表格编辑（推荐，改得多时用）**
「物料」页点 **✎ 表格编辑 A-G**，整张表变成可编辑网格，
物料名称 / 料号 / 类型 / 规格 / 宽幅 / 供应商 / 单位 / 状态 / 期初 / 安全库存
每一格都能直接改，横向滑动看后面的列，改完点 **保存全部修改**。

**② 勾选批量改（改某一列的规律内容时用）**
勾选物料（可全选）→ 选要改的列 → 执行。可选列：
**物料名称、料号、类型、规格、宽幅、供应商、单位、状态、期初结存、安全库存**。

- 文本列两种改法：**直接设为该值**（全部统一）或 **只替换部分内容**（如把宽幅 250 换成 260，供应商"松杨"改成"松杨电子"）
- 数字列（期初/安全库存）：**设为该值** 或 **增减**（填 -100 即批量扣减，不会减成负数）
- 批量 **停用 / 启用**：停用的不出现在录单下拉和库存页，数据仍保留
- 批量 **删除**：**有历史单据的自动改为停用**（保证流水可追溯），无单据的才真删

单条编辑：点任意物料进入详情页，A–G 列逐项改。

要找回停用物料：切到「含停用物料」→ 勾选 → 批量启用。

### 物料档案也能从 Excel / CSV 批量导入

「物料」页 → **批量导入** → 选文件 → 预览 → 确认。

- 支持 `.xlsx / .xlsm / .csv`，首行表头，也可先下载模板照着填
- **「物料名称」必填**，其余列可缺；表头认别名（品名/料号/编号/型号/类别/宽幅/预警值…）
- 匹配规则：先按**料号**、再按**名称**匹配已有物料
  - 合并更新（默认）：只补空字段，并用表里的期初/安全库存覆盖
  - 完全覆盖：表里所有非空值都覆盖（含物料名称）
  - 跳过已有：只导新物料
- 导入后会在物料页顶部显示"新增 X 项，更新 Y 项，跳过 Z 项"

> 没有表头也行，按 A=名称 B=料号 C=类型 D=单位 E=期初 读取。

### 单据用 Excel / WPS 表格直接导入

**入库页和录单页都有「⬆ 从 Excel / WPS 导入」按钮**（出库页也有，走 `/out/import`）。

支持 `.xlsx / .xlsm / .xls / .et(WPS) / .csv`，流程是 选文件 → 预览 → 确认导入。

表格怎么填（列顺序随意，缺列没关系，首行表头）：

| 日期 | 物料名称 | 料号 | 类型 | 规格 | 宽幅 | 供应商 | 单位 | 进 | 出 | 备注 |
|---|---|---|---|---|---|---|---|---|---|---|

**数量两种写法，任选其一：**

- **「进」「出」分两列**（推荐）：一行同时有进有出会生成两笔单据
- **「数量」+「进出」两列**：进出列填"进"或"出"；没有进出列时按页面默认类型（入库页=进、出库页=出）

导入时的行为：

- **在入库页导入**只取表里的"进"，出库行自动忽略；**出库页**反之（提示会写明忽略了几笔）
- 物料按 **料号 → 名称** 匹配；**表里没有的新物料会自动建档**，A-G 列信息一并写入
- **出库超库存的行会被跳过**并提示可用量（可勾选"允许超出库存"放行）
- 日期为空的行用页面上填的默认日期；`2026/9/3`、`2026年9月3日`、Excel 日期序列都能识别
- 表头认别名：单据日期/时间、品名/名称、编号/型号、入库数量/出库数量、客户/单号/摘要、类别/幅宽…

> WPS 用户：.et 直接导；老的 .xls 若报错，先另存为 .xlsx；CSV 支持 UTF-8 和 GBK。
> 不确定格式就先点**下载导入模板**照着填。

### 件数换算（数量 / 件数 / 每件）

录单页和导入都支持三个数：**总数量、件数、每件**，填任意两个自动算第三个。

- 数量 200 + 件数 3 → 每件 66.67（不可整除保留两位小数）
- 件数 5 + 每件 20 → 数量 100
- **只填总数量也完全可以**，件数和每件留空不影响记账

### 库存历史（台账）

物料列表、库存列表每行都有 **📈**，点进去看这种物料的全部进出记录，
每行带**当时的结存余额**（期初 + 进 − 出逐笔滚动），可按月份筛选。

### 排序与搜索

- **点表头列名排序**：物料页、库存页、流水页都能点，三态循环 默认 → 升序 ▲ → 降序 ▼
- **模糊搜索**：库存页搜名称/料号/供应商/类型/规格；流水页搜物料/料号/备注/类型。不分大小写

### 导出真正的 Excel

库存、流水、月报都能导出 `.xlsx`（带冻结首行、表头配色），
**导出的是当前筛选和排序后的结果**。月报导出保留原表"物料 × 每日进/出"的版式。

### 入库 / 出库分开录

底部导航 **📥 入库** 和 **📤 出库** 是两个独立页面，界面一样，都含原表 A-G 七列：

**入库页**：只能入，备注默认填"单号/客户"，适合收货时快速登记。
**出库页**：只能出，多一列 **「可用」实时显示当前库存**，数量一超就标红 ✕；
提交时**超出库存的行会被拦下不保存**，并提示"N 行因超出库存未保存：某某(可用多少)"，避免库存变负数。

两页互不干扰，各自有独立的历史流水（入库流水 / 出库流水），
也可去「流水」页看合并的全部单据。原来的通用「/txn」页仍保留，可在一行里选进或出。

### 录入页：照着原 Excel 的格子填

「录单」页就是原表的行样式，一行一笔，表头依次为：

**日期 ｜ 供应商 ｜ 类型 ｜ 规格（米）｜ 宽幅 ｜ 物料名称 ｜ 料号 ｜ 单位（卷）｜ 进/出 ｜ 数量 ｜ 备注**（还可加出 状态 / 期初 / 安全库存 列）

- 物料名称输入时会联想已有物料，**选中即自动带出其余 A-G 信息**
- 也可以整行手填一个**新物料**，保存时自动建档（期初、安全库存可直接在这一行填）
- 行里改了 A-G 任一格，保存时会同步更新该物料档案
- 只有填了**名称或料号**且**数量 > 0** 的行才会保存；日期留空的行默认用第一行日期
- 点 **＋ 再加一行** 可继续加行，一次提交多笔

### 改表头（列映射）

入库页底部 **⚙ 修改表头名称 / 显示 / 映射**，可自定义：

- **显示名**：比如把"类型"改成"类别X"、"物料名称"改成"品名"，入库页表头立刻跟着变
- **列序**：调整列的先后顺序
- **是否显示**：不用的列可关掉（如"状态"），入库页就不出现
- **导入别名**：Excel 导入时，用哪些名字认这一列（自定义的表头名会自动加入别名）

改错了点 **↺ 恢复默认** 即可。别名改完后，你自己的 Excel 表头不用改名也能直接导入。

### 系统自检 🔍

「物料」页 → **🔍 自检**（或访问 `/sys`），可以看到：

- **数据体检**：孤儿单据、缺名称的物料、非法日期/数量、负库存、重名物料，一条条列出来；一键清理
- **库概况**：物料数、单据数、起止日期、文件大小、数据库路径
- **一键备份**：生成 `.bak` 文件（在程序目录，自动保留最近 10 份）
- 启动时也会自动备份一份，并在窗口里提示体检结果

### 数据是怎么保住的（底层）

| 机制 | 作用 |
|---|---|
| 外键约束 | 删除物料不会留下无主单据（老库升级时自动开启） |
| WAL 模式 | 写入时读操作不卡；断电也不易损坏 |
| 事务 | 批量删除 / 批量导入 / 列映射保存，要么全成功要么全回滚 |
| 在线备份 | 用 SQLite 官方 backup API，拷出来的库一定是一致的 |
| 写前校验 | 数量非数字、NaN、负数一律挡下；日期非法自动回退到今天 |

**换手机 / 重装**：把 `warehouse.db` 复制走即可，全部数据就这一个文件。
出问题就把 `.bak` 改名回 `warehouse.db` 还原。

### 打包成 Windows exe（两种方式）

### 独立窗口模式

打包后的 exe **默认开独立窗口** —— 双击出来一个程序窗口，没有浏览器地址栏，
看起来跟普通桌面软件一样。

| 启动方式 | 效果 |
|---|---|
| 双击 exe | 独立窗口（推荐） |
| `仓库管理系统.exe --browser` | 用浏览器打开（排错时用） |

几个细节：

- **没有黑窗口**，报错会写进 exe 旁边的 `warehouse.log`
- **自动找空闲端口**，8080 被占用也不会起不来
- 万一 pywebview 在你的电脑上跑不起来（比如缺 WebView2 运行时），
  会**自动退回浏览器模式**并自动打开浏览器，功能完全一样
- 源码运行时默认浏览器模式，方便调试；想试窗口就 `python3 app.py --window`

**方式 A：让 GitHub 帮你打（推荐，不用装 Python）**

仓库里已经配好了自动打包流程。推送后打一个标签：

```bash
git tag v1.0 && git push origin v1.0
```

GitHub 会用官方 Windows 机器打包，几分钟后在仓库的 **Releases** 页面
就能下载 `仓库管理系统-windows.zip`。

**方式 B：本机打包**

双击 **`打包成exe.bat`**，产物 `dist\仓库管理系统.exe`（必须 Windows 系统）。
详见 **打包exe说明.md**（含杀软误报、端口占用、换图标等常见问题）。

> PyInstaller 不支持交叉编译，Linux/Mac/手机上打不出 exe。

### 上传到 GitHub

本地已经初始化好 git 仓库并做完了首次提交，直接跑：

按提示输入用户名和 **Personal Access Token**（不是登录密码，

## 三、首次使用三步走

1. **物料 → 逐个点开 → 填「期初结存」**（原表上月结存是坏值，无法继承，需手工录入一次）
2. 顺手填「安全库存（预警值）」，低于它会在首页和库存页标红
3. **首页 → 录入出入库**，以后只录单据，库存自动算

## 四、数据结构

- `materials` 物料档案：供应商 / 类型 / 规格 / 宽幅 / 名称 / 料号 / 单位 / 期初 / 安全库存 / 状态（常用·不常用·呆滞）
- `txns` 单据流水：日期 / 物料 / 进或出 / 数量 / 备注（单号、客户）
- `v_stock` 视图：实时库存，由单据聚合得出，不存冗余数

原模板的"呆滞/不常用"标记保留为物料状态字段；原表的"上月结存/本月结存"由 **期初 + 流水** 取代。

## 五、备份与迁移

```bash
cp warehouse.db warehouse_$(date +%F).db      # 备份
cp warehouse.db ~/storage/downloads/          # 导出到下载目录
```
数据库是单个文件，换手机复制走即可；放到 Termux 私有目录可避免被其他 App 误改。
