# 仓库管理系统 v3.109

从一份损坏的《仓库进出管理.xlsm》改造而来。原表 `#REF!` 满屏、公式不覆盖新行，
现在改成**单据流水驱动**——只录进出，库存自动算。

面向模切行业：卷料按「卷」和「平米」双口径记账，长 × 宽 自动折算，
零头自动写进备注；采购单与库存**完全解耦**，只靠批次号联系。

## 一、快速开始

### 手机（Termux）

```bash
pkg update && pkg install python
cd ~/wh/warehouse
chmod +x run.sh
./run.sh
```

首次运行自动装 Flask、建 `warehouse.db`。看到提示后浏览器打开
**http://127.0.0.1:8080**

```bash
PORT=9000 ./run.sh                      # 换端口
WAREHOUSE_DB=/sdcard/wh.db ./run.sh     # 数据库放别处
```

### 电脑（Windows）

双击 `打包成exe.bat`，产物 `dist\仓库管理系统.exe`，双击自动开浏览器。
详见 `打包exe说明.md`。

> PyInstaller 不支持交叉编译，**exe 只能在 Windows 上打**。

## 二、六大模块（v3.37 起模块化）

整个系统拆成六个互不纠缠的模块，**谁先谁后、怎么拼在一起由 `wh/dispatch.py` 决定**。
单个模块可以独立看、独立改，不用在几千行里翻。

| 模块 | 目录 | 行数 | 管什么 |
|---|---|---|---|
| **制表** | `wh/sheet/` | 8374 | **电子表格**：内核 / 求值 / IO / 动作 / Web 五层 + 批次号（内核函数库 10 个子模块、求值层 8 个、动作层 6 个、Web 层 5 个） |
| **表格** | `wh/table/` | 1434 | 通用录入表：列定义、导入预览、录入表单（不再提供路由） |
| **采购** | `wh/po/` | 1901 | 采购单、批次、到货、付款（拆 6 个逻辑文件 + web/ 5 个路由文件） |
| **出入库** | `wh/txn/` | 1233 | 入库、出库、流水、Excel 导入（拆 3 个文件：录入 / 导入 / 列表删除） |
| **统计** | `wh/stat/` | 1122 | 首页、月报、**统计中心八张表**（拆 2 个文件：月报 / 统计中心） |
| **盘点** | `wh/count/` | 454 | 盘点单、实盘、差异、调整入账 |
| **库存** | `wh/inv/` | 406 | 物料档案、库存视图、批量操作 |
| **UI** | `wh/ui/` | 443 | 配色、骨架、组件 |
| **核心** | `wh/core/` | 2536 | 数据库（拆 7 个子模块）、路由、错误处理、工具、通用报表导出 |
| **调度** | `wh/dispatch.py` | 143 | 装配以上所有模块 |

业务模块**不互相 import**，需要制表能力就调表格模块的门面 `tbl`：

```python
from ..table import tbl
tbl.fingerprint(headers)          # 列名指纹（判断两张表是不是同一类）
tbl.evaluate('qty*price', vals)   # 公式求值
tbl.preview(path)                 # Excel 导入预览
tbl.xlsx_response(headers, rows, '库存.xlsx')   # 导出
```

## 三、表格模块：类 Excel 制表台

自研制表台按主流开源表格项目的能力清单自建，**零业务耦合、可独立运行**，
依赖只有 `openpyxl`。没用 Handsontable（商用要钱）、Luckysheet（2024-11 已停更）。

**双引擎**（v3.77 起统一为单一入口，默认新引擎，可一键切换）：

| 引擎 | 授权 | 定位 |
|---|---|---|
| **Univer**（默认） | Apache-2.0 | 工业级渲染，Canvas，500+ 函数、条件格式、筛选、图表、透视表 |
| **自研制表台** | — | 离线兜底，175 个公式，Univer 资源缺失时自动接管 |

图表用 **ECharts**（Apache-2.0）、透视表用 **VTable**（MIT）——这两样 Univer 官方放在
Pro 商业版，用同等授权的开源件补齐，不碰商业授权。

计算层另有 **IronCalc**（Apache-2.0 / MIT 双许可）作交叉验算后端，`wh/table/ironcalc_backend.py`，
不装也不影响主程序运行。

> ⚠️ **Univer 是 Open Core 模式**：核心仓库 Apache-2.0，但部署包分 Free / Pro。
> Free 未授权版有限制：**导入文件 ≤ 1MB、导出 ≤ 10000 个单元格、打印 ≤ 3 页**、
> 每文档 1 个透视表、图表仅线/柱/饼/条 4 类。深度定制需向官方取得授权。

### 列与列名识别

- **只有一套列**。系统不再按"模板"分套列定义——需要不同的表格，
  到**制表模块**去做，那里的表格就是主体
- **列名指纹**：表头去空格、去括号、排序后拼接。顺序不同、括号写法不同
  都算**同一类**；少一列或多一列算不同类
- **导入自动识别**：上传后算指纹，命中就自动对上列
- **长 × 宽 = 平米**：选中物料自动带出档案里的长/宽；填平米算卷数，
  填卷数算平米，零头自动写进备注

## 四、采购与库存：两套账，只靠批次联系

这是 v3.30 之后的核心设计。

### 关系图

```
采购单 ──(建单生成批次号)──▶ 明细行
                                │
入库页填批次号 ─────────────────┘
        │
        ├──▶ 一份进库存（txns）
        └──▶ 一份进采购流水（用于结单）
```

**删掉入库单，采购的到货数不变。两套账没有外键绑定。**

### 到货按入库录入算（v3.35）

采购页**不再手工登记到货**。在入库页录一笔、填上批次号，保存后自动一分为二：

| 动作 | 结果 |
|---|---|
| 入库 25 平米（换算率 5） | 采购记到货 **5 卷**，状态 → 部分到货 |
| 再入库 25 | 凑够 10 卷，状态 → **已完成** |
| 再入库 50 | 已交齐，这次不计入，并提示 |
| 删掉入库单 | 采购到货数**纹丝不动** |

### 采购明细列（v3.101 起）

**采购模板整套已下线**。明细列不再由模板决定——需要什么列，
就到制表模块把表头做成什么样，下单时映射过去。

- 明细按列记：物料 / 长 / 宽 / 平米 / 卷料 / 单价 / 金额
- 长 × 宽 = 一卷平米，平米 ↔ 卷料双向推算，零头自动写「余料 X 平米」
- 数据层 `po_tpl` 表保留（历史 `po_items.ptpl_id` 仍引用），仅不再暴露入口

## 四之二、盘点（v3.40 新增）

标准账实核对流程，字段对齐通用盘点单模板：

```
建盘点单（按账面数生成空白表）
   → 打印出来现场盲盘，填「实盘数」
   → 自动算「差异 = 实盘 − 账面」「差异率」
   → 填差异原因、处理意见
   → 点「调整入账」，按差异生成盘盈入库 / 盘亏出库
```

**盘点单本身不动库存**，只有最后「调整」那一步才生成单据。好处：

- 盘点期间可以继续收货发货，不受影响
- 差异原因、处理意见、谁盘的谁监盘，全都留得下痕迹
- 调错了可以「撤销调整」，删掉本次生成的单据，库存回到盘点前

| 操作 | 库存 | 说明 |
|---|---|---|
| 建单 / 填实盘 / 保存 | **不动** | 账面数是建单那一刻的快照，之后出入库不会改它 |
| 调整入账 | 生成单据 | 盘盈→入库单，盘亏→出库单，备注写明原因和单号 |
| 撤销调整 | 删单据 | 按记录的单据 id 精确删除 |
| 删盘点单 | 不动 | 已调整的单子要先撤销，避免留下无主单据 |

导出格式：盘点单号 / 日期 / 范围 / 物料编码 / 名称 / 规格 / 单位 /
**账面数量 / 实盘数量 / 差异数量 / 差异率** / 单价 / 差异金额 /
差异原因 / 处理意见 / 盘点人 / 监盘人 —— 差异行自动标红。

## 四之三、统计中心（v3.40 重做）

访问 `/stat`，八张表，覆盖通用仓储统计报表的常见口径：

| 表 | 内容 |
|---|---|
| 收发存汇总 | 期初 / 本期入库 / 本期出库 / 期末 / 单位成本 / 期末金额 |
| 周转分析 | 平均库存 / 本期出库 / 周转率(次) / 周转天数 |
| 呆滞库存 | 期末库存 / 库龄(天) / 库龄区间 / 金额 / 处理建议 |
| ABC 分类 | 期末金额 / 累计占比 / A·B·C / 管理重点 |
| 安全库存预警 | 当前 / 安全库存 / 差额 / 状态 / 建议措施 |
| 进出趋势 | 近 24 个月 进 / 出 / 净额 / 金额 / 单据数 |
| 维度统计 | 按类型、按供应商 汇总进出数量与金额 |
| 盘点差异 | 每次盘点的盘盈盘亏种类、数量、金额 |

**口径写死在这里，避免各处各算一套：**

```
期初 = 档案期初 + 期间开始前的进 − 期间开始前的出
期末 = 期初 + 本期入库 − 本期出库
平均库存 = (期初 + 期末) / 2
周转率 = 本期出库 / 平均库存        周转天数 = 期间天数 / 周转率
库龄 = 今天 − 最后一次出入库日期    呆滞 = 库龄 ≥ 90 天且还有库存
金额 = 数量 × 最近一次填过的单价（没填过单价的按 0 计，不瞎估）
```

每张表都能导出 Excel / CSV（带防公式注入处理）。

## 五、模切行业的卷料口径

### 长 × 宽 → 平米 → 卷数

```
一卷平米 = 长 × 宽
卷数     = 总数量 ÷ 一卷平米（向下取整）
余料     = 零头，自动写进备注
```

例：长 100 米 × 宽 0.05 米（一卷 5 平米）

| 你填的数量 | 平米 | 卷料 | 备注 |
|---|---|---|---|
| 250 | 250 | **50** | — |
| 253 | 253 | **50** | 余料 3 平米 |

### 双向自动换算

- 先填**平米** → 自动算卷数（取整，有零头写备注）
- 先填**卷数** → 自动算平米
- 数量框旁有「数量按 平米 / 卷」下拉，两种填法都支持

### 单位：每列自己配，不再有独立单位列

在「⚙ 改表头」里给每列填单位，表头就显示成 `长（米）`、`宽（米）`、
`平米（平米）`、`卷料（卷）`。**留空就是不带单位**。

## 七、数据怎么保住的

| 机制 | 作用 |
|---|---|
| 外键约束 | 删物料不会留下无主单据 |
| WAL 模式 | 写入时读不卡，断电不易损坏 |
| 事务 | 批量删除/导入/列映射，要么全成功要么全回滚 |
| 一次性令牌 | 挡住网络卡顿时连点两下造成的重复记账 |
| 写前校验 | 数量非数字、NaN、负数一律挡下 |
| 在线备份 | SQLite 官方 backup API，拷出来的库一定一致 |
| 启动自检 | 数据库损坏时给出明确指引，不清空数据 |

**换手机 / 重装**：把 `warehouse.db` 复制走即可，全部数据就这一个文件。
